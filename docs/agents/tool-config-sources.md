## Known gaps after the 2026-11-06 pass

Nothing from this pass is left without an editor. The 2026-11-06 fields are
either dedicated inputs or a combined advanced-JSON editor:

- **Codex**: all provider keys plus the two top-level compaction keys.
- **Hermes**: provider request knobs, per-model capabilities, `model.api_mode`
  and `model.streaming`.
- **OMP**: 15 roles, thinking level, presets, model/provider extras.
- **Pi**: model `inputLimits` / `promptCache` / `samplingParams*` in one JSON
  block (they are proxy-specific request tuning, not everyday settings).

The next pass should re-run the URL list above; fields introduced after
2026-11-06 are preserved by the lossless apply but will need an editor.

## Channel import (shared inference)

`channelimport` (pure rules) + `importflow` (channel/token/model resolution) +
the `pi` / `omp` builders are the single implementation behind the GUI dialog,
`dg pi providers import` / `dg omp providers import`, and the TUI's
Pi → Providers / OMP → Providers `i` action. If a channel platform or API
protocol changes, update `wails/internal/service/channelimport` only.
